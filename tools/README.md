# PASR Python Tools - Essential AI/Optimization Toolkit

Directory untuk Python ecosystem tools yang mendukung EA PASR, terutama validasi, preprocessing, training MLP, confidence calibration, ONNX export, walk-forward, dan simulasi.

---

## Setup

```bash
pip install -r tools/requirements.txt
```

---

## Recommended AI Workflow

### 1. Preprocess training data

Input CSV harus berisi `f0..f33`, `label`, dan optional `weight`.

```bash
python tools/preprocess_ai_training_data.py \
  --input AI_Training_Data_Template.csv \
  --output output/AI_Training_Data_Processed.csv
```

### 2. Train MLP weights for `AIInference.mqh`

```bash
python tools/train_mlp.py \
  --csv output/AI_Training_Data_Processed.csv \
  --out output
```

Output:

- `output/PASR_mlp_m0.bin`
- `output/PASR_mlp_m1.bin`
- `output/mlp_training_report.json`

Copy `PASR_mlp_m0.bin` dan `PASR_mlp_m1.bin` ke:

```text
MT5/MQL5/Files/
```

`AIEnsemble.mqh` akan mencoba memuat file ini otomatis. Kalau file tidak ada atau tidak cocok, EA tetap fallback ke bobot default/random.

### 3. Train confidence calibration for `ConfidenceCalibrator.mqh`

Input `PASR_calibration.csv` harus berisi minimal:

```text
score,outcome,rr
```

Dengan `outcome`: `+1` win, `-1` loss, `0` pending/ignored.

```bash
python tools/retrain_ensemble.py \
  --csv PASR_calibration.csv \
  --out output
```

Output:

- `output/PASR_calibration_params.bin`
- `output/calibration_params.json`
- `output/calib_report.html`

Copy `PASR_calibration_params.bin` ke:

```text
MT5/MQL5/Files/
```

`ConfidenceCalibrator.mqh` akan mencoba memuat file ini otomatis saat init.

### 4. Optional ONNX sequence model

```bash
python tools/export_onnx.py --out output/PASR_sequence.onnx
```

Output ONNX mengikuti kontrak `ONNXBridge.mqh`:

- input: `[1, 64, 12]`
- output: `[1, 2]` yaitu `[direction, confidence]`

Copy `.onnx` ke `MT5/MQL5/Files/`, lalu aktifkan ONNX di config EA.

## Core Tools

### `train_mlp.py` — Main MLP Training Exporter

Melatih MLP `34->64->32->1` dari CSV fitur `f0..f33` dan mengekspor bobot binary yang kompatibel dengan `AIInference.mqh::LoadWeights()`.

### `retrain_ensemble.py` — Confidence Calibration Pipeline

Melatih parameter Platt/confidence calibration dari `PASR_calibration.csv` dan mengekspor `PASR_calibration_params.bin` untuk `ConfidenceCalibrator.mqh`.

### `walkforward_harness.py` — Walk-Forward Test Harness

Membagi rentang tanggal menjadi beberapa window IS/OOS, menjalankan backtest MT5, dan mengagregasi hasil ke HTML report.

```bash
python tools/walkforward_harness.py \
  --symbol EURUSD --tf H1 \
  --start 2023-01-01 --end 2025-12-31 \
  --windows 6 --is-ratio 0.70 \
  --out wf_output
```

### `optimization_manager.py` — Optimization Automation

Automates systematic parameter optimization for MT5 Strategy Tester.

### `run_optimization.sh` — Optimization Runner

Shell script untuk menjalankan optimization di Linux/Wine environment.

### Simulator Tools

- `pasr_simple_simulator.py` — simple backtesting simulator tanpa dependency berat
- `pasr_strategy_simulator.py` — advanced strategy simulator dengan numpy/pandas

### Data Processing and Validation

- `preprocess_ai_training_data.py` — preprocess AI training data
- `strategy_tester_validation.py` — validate strategy tester setup
